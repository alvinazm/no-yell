# 「和颜悦色」家长情绪监测助手 — 设计文档

- 日期:2026-09-01
- 状态:已与用户确认(总体架构 + 分析引擎两轮设计确认)
- 工作名:「和颜悦色」(英文 CalmTutor,名字可随时更换)

## 1. 产品概述

一款面向辅导孩子作业的家长的情绪监测 Web 应用(PWA)。家长在辅导前选择监测模式,
应用通过麦克风(音量、语速、负面关键词)和/或摄像头(表情、动作)实时分析家长情绪,
在情绪到达临界点前用温和的 AI 语音播报 + 屏幕气泡提醒;辅导结束后给出情绪复盘报告。

核心原则:**所有音视频数据只在设备本地处理,不保存、不上传云端**。

## 2. 产品形态与页面流程

单页应用(PWA),可通过浏览器访问并安装到主屏幕/桌面。

### 2.1 首页 · 模式选择

- 三个模式卡片:仅麦克风 / 仅摄像头 / 双开
- 使用说明与隐私承诺("数据只留在你的设备上")
- 点击开始后请求对应权限(麦克风、摄像头)

### 2.2 监测页(辅导进行中)

- 顶部:实时状态球(绿 = 平稳 / 黄 = 紧张 / 红 = 危险)+ 当前紧张度(0-100)
- 中部:实时反馈区——当前分贝值(麦克风模式)、当前表情状态(摄像头模式)
- 底部:辅导计时器 + 结束按钮
- 触发提醒时:屏幕弹出柔和气泡 + AI 语音播报,不打断辅导

### 2.3 结果页(辅导结束)

- 情绪稳定得分(0-100 大数字 + 评级)
- 五项指标卡:辅导时长、声音平均分贝、视频异常次数、系统提醒次数、情绪得分
- 温和建议 + 本次会话摘要存档(仅统计数字,无音视频)
- 历史记录列表(从 localStorage 读取,可清空)

## 3. 技术架构

工程化 PWA:Vite + React + TypeScript,`vite-plugin-pwa` 支持离线安装。

```
src/
  components/     # ModeSelector / MonitorView / ReminderOverlay / ResultsView
  hooks/          # useAudioMonitor(分贝+关键词)
                  # useVideoMonitor(MediaPipe 表情分析)
                  # useSession(会话状态机:空闲→监测中→已结束)
  lib/
    emotionEngine # 双通道融合的紧张度判定
    speech        # 语音播报 + 分级话术库
    scoring       # 情绪得分算法
    storage       # localStorage 历史摘要
  types.ts
```

### 关键依赖

- MediaPipe Face Landmarker:表情特征提取,设备本地推理
- Web Speech API:语音识别(转写中文)与语音播报,系统自带,无需 API key
- Web Audio API:分贝采样与分析
- vite-plugin-pwa:离线安装能力

## 4. 分析引擎

### 4.1 音频通道(麦克风)

- 通过 `AudioContext` + `AnalyserNode` 每 100ms 采样一次分贝
- 检测"音量骤升":1 秒内上升超过 10dB 记为一次冲击
- 使用语音识别持续转写中文,匹配负面关键词("怎么这么笨"、"烦死了"、
  "说了多少遍"、"气死我了"等,完整列表在代码中集中维护);命中视为高风险信号
- 音频紧张度(0-100):
  - 基础分贝映射:60dB≈0、75dB≈50、85dB≈100(线性插值)
  - 骤升或负面关键词命中直接上抬分数(每次骤升 +15,命中关键词 +30,
    同一关键词 30 秒内不重复计分)
  - 上抬后封顶 100

### 4.2 视频通道(摄像头)

- MediaPipe Face Landmarker 每 200ms 提取面部特征:
  - 皱眉度:左右眉毛内角下压距离
  - 嘴部紧张:嘴角下拉 / 嘴唇压力
  - 头部动作:快速点头 / 晃动
- 组合为视频紧张度(0-100),单帧抖动用最近 3 次采样滑动平均平滑

### 4.3 双通道融合

- 仅单通道:直接使用该通道分数
- 双开:音频 × 0.6 + 视频 × 0.4(权重可调)
- 融合结果同样做 3 次滑动平均,避免单帧抖动

## 5. 提醒规则

- 黄色提醒:紧张度 60-79,轻柔话术,如"深呼吸一下,慢慢来"
- 红色提醒:紧张度 ≥80,强提醒话术,如"情绪到临界点了,先离开一分钟"
- 同一级别提醒后 30 秒冷却,避免连续轰炸
- 话术库:每级 4-5 条,随机轮换;播报(speechSynthesis)与屏幕气泡同步

## 6. 结果与算分

### 6.1 情绪稳定得分(0-100,越高越稳定)

从 100 分起扣减:

- 每次黄色提醒:-3 分
- 每次红色提醒:-8 分
- 平均分贝超过 65dB 后,每满 5dB 再扣 2 分
- 每次 85dB 以上冲击:-1 分
- 下限 20;辅导时长不足 5 分钟时扣分减半(避免偶然异常拉低分)

### 6.2 评级

- ≥85 优秀
- 70-84 良好
- 50-69 需要留意
- <50 需要休息

### 6.3 五项指标口径

- 辅导时长:开始到结束的实际秒数
- 声音平均分贝:全程采样均值(仅麦克风模式时展示)
- 视频异常次数:视频紧张度 ≥80 的连续帧段数量(连续的算一次)
- 系统提醒次数:实际触发的播报次数
- 情绪得分:6.1 节算法结果

## 7. 数据与隐私

- 音视频流仅用于实时分析,不录制、不保存、不上传
- 会话结束后仅将统计摘要(时长、平均分贝、异常次数、提醒次数、得分、时间戳)
  写入 localStorage,供历史记录展示
- 提供"清空历史"操作

## 8. 错误处理与降级

- 拒绝权限:返回首页提示,不启动监测
- 无摄像头 / 浏览器不支持:摄像头模式按钮禁用,引导使用麦克风
- 语音识别不可用(Firefox/Safari):自动降级为仅分贝检测,页面提示
  "关键词识别不可用"
- MediaPipe 模型加载失败(如离线):视频模式降级为仅音频,提示原因
- 监测中页面意外关闭:不做恢复,进入时提示"上次辅导已中断"

## 9. 测试策略

- 引擎单测(Vitest):阈值、冷却期、融合权重、滑动平均
- 算分单测:不同输入组合的得分与评级
- 负面关键词匹配单测
- 三种模式(麦克风 / 摄像头 / 双开)的手动验证流程
