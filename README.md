# 和颜悦色（no-yell）

AI 家长情绪监测助手 —— 辅导作业，也照顾好自己。

在辅导孩子作业时实时监测家长的情绪状态，通过声音与面部表情识别情绪压力，及时给出温和提醒，并在结束后生成情绪稳定报告。

## 功能特性

- **三种监测模式**：仅麦克风（音量、音量突增与负面用词）、仅摄像头（表情与动作）、双开（声音 + 表情融合判断）
- **实时情绪状态**：0–100 压力值，绿（平稳）/ 黄（紧张）/ 红（危险）三级提示
- **及时提醒**：情绪紧张或危险时显示提醒浮层并语音播报中文提示语（30 秒冷却，避免频繁打扰）
- **辅导报告**：结束时生成情绪稳定得分与评级（优秀 / 良好 / 需要留意 / 需要休息），并汇总辅导时长、平均分贝、异常次数与提醒次数
- **历史记录**：本地保存最近 50 次辅导记录，可随时查看或清空
- **隐私优先**：所有分析均在设备本地实时完成，音视频不录制、不上传
- **PWA 支持**：可作为应用安装到桌面

## 技术栈

- Vite + React 18 + TypeScript
- MediaPipe Tasks Vision（面部关键点识别）
- Web Audio API（音量分析）
- Web Speech API（负面用词语音识别与提醒语音播报）
- Vite PWA 插件
- Vitest（单元测试）

## 快速开始

前置要求：Node.js 与 npm。

```bash
# 安装依赖
npm install

# 启动开发服务器（默认 http://localhost:5173）
npm run dev

# 或使用项目自带启动脚本（固定 5170 端口，端口被占用时先释放再启动）
./start.sh

# 构建生产版本
npm run build

# 本地预览生产构建
npm run preview

# 运行测试
npm test
```

## 使用说明

1. 打开应用，选择监测模式：
   - 仅麦克风：分析音量、音量突增与负面用词
   - 仅摄像头：分析表情与动作，适合轻声辅导
   - 双开：声音 + 表情综合判断，识别最准
2. 浏览器会请求麦克风 / 摄像头权限，允许后开始实时监测
3. 监测过程中，压力值变黄或变红时，应用会显示提醒并语音播报
4. 点击「结束辅导」查看本次情绪稳定得分、评级与历史记录

> 提示：监测功能需要浏览器授予麦克风 / 摄像头权限；负面用词识别与提醒播报依赖浏览器的 Web Speech API 支持。
